# 运行管理

从左下角用户头像展开菜单，选择“运行管理”。此入口仅提供配置查看和运行追踪，不写入 Prompt、Skills 或 MCP 连接配置。没有选择项目时也可以使用。

页面包含总览、Agent、MCP、Skills、运行记录。配置从统一的 `patentcompass_agent` 加载器、`tool_service.catalogue()` 和内置运行层 `definitions()` 读取，工具数量随实际注册结果变化。当前有一个主 Agent、五项 Skills、39 项 MCP 工具、26 项内置 Agent 工具；`prepare_agent_action` 是宿主专用工具。

主 Prompt 与原系统宿主适配 Prompt 分别展示原文、来源、SHA-256 和复制入口。Skills 支持查看 `SKILL.md` 和受控参考文件。MCP 展示后端挂载的 Streamable HTTP 端点及工具参数 Schema。“已配置”仅表示必要参数齐全，不代表模型服务或外部 MCP 客户端已验证连通。

管理页使用独立的 `management` 及 `management_*` URL 参数，保留原项目、对话、研究、报告版本和选段。打开期间原业务组件保持挂载；关闭后恢复原页面和草稿。点击项目或业务入口会退出管理页。

## 只读接口

- `GET /api/management/configuration`：当前用户显示信息、模型配置状态、Prompt、Skills 元数据与两类工具定义。
- `GET /api/management/skills/{name}?reference=...`：技能或参考文件的原文、来源及指纹；复用受控资源加载器，不接受任意路径。
- `GET /api/management/runs?project_id=...&status=...&limit=20&cursor=...`：当前 owner 的主任务，按创建时间倒序；每页上限 100，子任务在详情展示。
- `GET /api/management/runs/{id}`：状态、执行计划摘要、等待确认信息、运行配置快照、子任务和产物链接。
- `GET /api/management/runs/{id}/events?after=0&limit=100`：按序号分页读取管理事件摘要，每页上限 200。

接口显式挑选公开字段，不返回完整任务 payload、模型协议、生成参数或凭据。任务查询沿用现有 owner 规则；当前是原系统的本地用户模式，没有新增独立账号或管理员角色。

## 当前配置与历史运行

任务详情仅从已保存的运行状态中读取主 Prompt、宿主 Prompt、已加载技能及参考文件，旧任务缺少的模型名和工具清单显示“未记录”，不会用当前配置填充历史。

新任务另外保存启动时模型名、实际采用的工具定义及指纹。工具事件携带 `call_id`、轮次和返回／错误摘要；等待用户确认不算工具成功，工具返回也不等于业务子任务成功。业务状态和产物分别展示。活跃详情每五秒更新，任务结束时补取最终事件后停止轮询。
