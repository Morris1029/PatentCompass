# PatentCompass 后端实施与验收记录

2026 年 10 月 19 日，按后端实施计划完成 29 个业务接口、显式数据库迁移和 Docker 后台任务。前端未接入，原始专利工作簿及既有产品说明未改动。

## 已实现范围

- FastAPI、Pydantic 2、SQLAlchemy 2、psycopg 3、Alembic，使用 Python 3.11 与 uv 锁定依赖。本地 API 监听 `127.0.0.1:8000`。
- 独立 Compose 工程 `patentcompass-dev`：PostgreSQL 17＋pgvector、Redis 7、Linux Celery worker；数据库及 Redis 仅映射到本机，业务文件持久化到 `storage/`。
- 19 张业务表，UUID、UTC、JSONB、外键、查询索引和业务唯一约束。应用启动不建表；现有首个迁移与模型无漂移。
- 项目、不可变范围版本、单数据版本绑定、上传或文件 ID 导入、质量与来源说明、字段/关键词/语义/混合检索。
- 运行与派发记录同事务保存，API 补偿派发；步骤检查点、执行租约与心跳、取消、确认续跑、失败重试、持久化 SSE 事件及断线续读。
- 对话以首条有效消息落库，按消息固定上下文；历史报告引用固定范围、数据和分析集合。可配置模型执行有次数限制的只读检索工具调用，并保存实际原文引用。
- 真实年度、共同申请人全计数、多 IPC 标签统计；图表配置、下钻集合和证据使用分析快照。语义候选最多 500 条，与总体数量分开返回。
- 报告正文块、图表配置和数据、证据、排版参数随版本冻结；支持明确块替换、并发校验、旧版本采用及分支修改。
- 指定版本 Word 导出由 worker 使用 ECharts SVG SSR、Sharp、中文字体和 python-docx 完成。

运行产物位于忽略提交的 `storage/acceptance/`，每次脚本执行创建独立验收项目。第一轮记录目录为 `20261019T103138Z-7c0db42a`，最后一次完整闭环为 `20261019T103714Z-0fa20098`。

`scripts/failure-smoke-test.py` 实测 Redis 中断时任务仍持久化并在恢复后完成；worker 停机时任务排队并在恢复后完成；重新创建本项目 PostgreSQL 容器后，API 自动重连，原项目、520 条申请、报告版本及已导出文件仍可读取。结果保存在相应验收目录的 `result.json` 中。

执行中断也已实测：导出任务保存 `export_snapshot` 检查点后强制终止 worker，90 秒租约到期后同一运行恢复并在第 2 次执行时成功；检查点 ID 与完成时间未变，数据库中该运行只有一份导出文件、一个唯一检查点。恢复后的 Word 仍为指定 V1，包含三张图及原始统计正文。该记录保存在最后一次完整闭环目录的 `fault_checks.worker-interrupted`。

## 仍需后续验证的边界

外部聊天及 embedding 服务默认关闭。未配置时不生成 AI 技术分析，不把受控模型测试当作真实服务验收。当前技术视图提供 IPC 结构，语义路线、机会判断与地域布局明确返回不可用原因。

Word 已核验真实下载、正文与版本一致、三张内嵌图、中文图表可读及页码字段；**整篇分页视觉验收尚未完成**。已使用文档技能附带的 `render_docx.py` 尝试渲染，当前 bundled runtime 缺少 `soffice.exe`，返回 `FileNotFoundError`。不能据此声称没有跨页或排版问题。

本轮不包含前端接入、PDF 导出、Word 资料正文解析、外部专利库、完整法律状态与同族分析，也不包含对外登录和组织权限。
