# PatentCompass 前后端集成与验收

本轮已按静态原型落地独立 `web/`，并补齐前端所需的后端能力。原型目录未修改；业务数据、消息、分析、图表、报告和任务状态均来自服务端持久化结果。

## 运行与技术

- 本地 Next.js 16.4.2、React 19.3.1、TypeScript、Tailwind、Zustand、SWR、ECharts、Tiptap，pnpm 锁定依赖。
- 本地 FastAPI、Python 3.11、SQLAlchemy、psycopg、Alembic；Docker PostgreSQL 17＋pgvector、Redis 7、Linux Celery worker。
- 前端 `127.0.0.1:3000`，API `127.0.0.1:8000`，数据库 `127.0.0.1:15432`，Redis `127.0.0.1:16379`。前端仅同源流式转发 HTTP、上传、下载和 SSE；密钥保留在后端。
- Compose 工程仍为 `patentcompass-dev`，原有数据卷和文件保留。worker 增加 LibreOffice、中文字体及既有 ECharts/Sharp 图表导出环境。
- 增量迁移 `3f618bc985fc` 已执行；旧图表 ID 回填为首个历史版本，旧报告正文与嵌入图表未重写。迁移不调用模型。

启动见根目录 README、`web/README.md` 和 `api/README.md`：分别运行 `scripts/start-dev.ps1` 与 `scripts/start-web.ps1`。Swagger 位于 `http://127.0.0.1:8000/docs`。

## 交付功能

项目与对话支持首次有效发送后保存、独立对话历史、共享范围和数据、附件草稿、报告引用、真实步骤与成果卡。浏览器只保存草稿元数据、界面偏好、运行标识和事件游标；SSE 可补读，断线不取消后台任务。

五个工作台页签接入真实统计和成果：概览、态势分析、布局与路线图、范围与目标、数据与证据。年度、申请人、IPC、来源国家、三个语义维度及两类交叉矩阵共九类图表均有独立版本、原文下钻和三种编辑模式。局部筛选明确显示实际统计数量与已保存条件，不改变项目共享范围。

Word 资料支持 DOCX 正文、表格及 Linux LibreOffice 的 DOC 转换，保存文件版本和段落/单元格定位。多个附件可在发送前移除，解析失败保留草稿并可重试；资料不计为专利申请。

补充 Excel 基于原申请号生成新完整版本，非空差异逐项选择旧值、新值或多值合并；公开日期冲突同样确认。原始文件、行级来源、基础版本和合并指纹保留。未通过质量检查或未解决冲突的版本不可绑定；就绪后仍需明确采用。

对话采用持久化受约束计划，只执行问答检索、范围、数据选择、分析、报告和图表操作。计划与版本固定保存；范围、数据和修改目标不足时沿同一运行等待确认。并发变化返回 409，保留输入并要求明确核对。报告追问读取被引用的冻结分析和文字，不发送整份图表配置。检索工具区分单式 AND 与多式并集，保存逐式计数及去重证据。

报告以稳定块 JSON 为权威，Tiptap 提供编辑和选择。支持标题、单段/多段、整章有序操作、真实路线图、图表插入/更新/移除、宽度、对齐及页面设置；全体验证后原子保存新版本。浏览不改变采用版本；切回后继续修改保留原分支。网页与 Word 使用同一冻结内容、图表和排版。

## 自动验证

自动测试使用独立 `patentcompass_test` 数据库、回滚事务和受控模型替身，不读取真实模型能力用于模拟成功。覆盖原有接口兼容、导入、统计、资源归属、版本冲突、持久化步骤、租约恢复、重复投递、等待输入、取消、失败重试和各类编辑操作。

另覆盖真实中断窗口：成果已提交但运行尚未完成时，重试沿祖先复用分析、报告、消息和文件；不会重复生成消息、回切采用分支或重新绑定最新计划版本。资料取消后重新选择同一文件可创建新解析任务。

前端 `pnpm typecheck` 与 `pnpm build` 通过。数据库 `alembic check` 无待补迁移。后端最终测试数量见本文件末尾的最终结果。

## 复现

```powershell
Set-Location api
uv run --frozen pytest -q
uv run --frozen alembic check
Set-Location ../web
pnpm typecheck
pnpm build
```

独立数据闭环脚本 `scripts/frontend-data-smoke-test.py` 会创建专用验收项目；`scripts/frontend-runtime-smoke-test.py <project_id>` 通过默认前端端口执行真实任务；`scripts/semantic-acceptance.py <run_id>` 对已完成的 520 条全量运行做独立核对。真实模型脚本会实际请求已配置服务，普通 pytest 不调用真实模型。

## 边界

本轮不接外部专利库，不执行外部补检；候选方向不是已证明的技术空白或法律结论。缺少省市、有效保护地、完整法律状态、权利要求和同族字段时明确展示原因。当前仍为固定内部试用身份，不包含完整登录/组织权限。报告不提供 PDF 导出，视觉 QA 中的 PDF 仅为本地检查中间产物。
