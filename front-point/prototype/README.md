# 行业专利导航原型

本地打开 `index.html`。一个项目保存一套研究底稿，多次对话共同完善底稿，报告版本归项目管理。

## 页面与入口

- **研究对话**：项目名称右侧“＋”打开空白对话，首次发送有效文字或 Word 附件后才保存到历史，首条消息自动命名。未发送的空白对话不占历史记录。
- **分析工作台**：提供“概览”“态势分析”“布局与路线图”“范围与目标”“数据与证据”五个页签。侧栏进入工作台时默认概览，已有明确页签与分析视角的链接继续恢复原位置。
- **导航报告**：项目统一管理报告版本；真实项目尚无报告时保持空状态，提供同页“体验报告编辑”入口。侧栏顺序为项目名称、分析工作台、导航报告、对话历史。
- **同页报告编辑体验**：进入项目的“导航报告”后点击“体验报告编辑”，直接在现有项目与报告页面体验 V3→V4、差异、引用和切回旧版；不切换到独立预览项目。示例支持标题与行文优化，以及“完善布局与路线图”追加章节；所有内容保留示例与待验证标记，不包含真实专利分析结论。

所有主要视图都在 `index.html` 的同一页面壳中切换，避免本地文件浏览器按 HTML 文件隔离存储。其余 HTML 文件保留旧链接入口，携带项目、对话、页签和相关定位跳到统一工作台；旧 `report-edit-preview.html` 现在只跳转到项目内的导航报告。

## 交互与数据边界

- 沿用静态 HTML、共享 CSS 和原生 JavaScript，无构建依赖、模型服务或后端。
- 全局“新建项目”只保存项目并打开首个空白对话；项目右侧“＋”打开新对话草稿，共用项目范围及数据状态。反复点击不会生成空历史记录。
- 桌面侧栏在 280px 和 64px 图标栏间切换并记住偏好；移动端使用遮罩抽屉，支持关闭按钮、遮罩、Escape 及焦点限制。
- 输入框可选择多个 `.doc`、`.docx` 文件。发送前可移除，支持仅发送附件；发送后在消息及工作台“项目资料”中显示附件信息。只保存文件名、大小、类型、修改时间等元数据，不上传文件、不读取正文。Word 附件不代表专利数据已就绪。
- 范围提取只使用用户文字中明确写出的信息。缺失项目保留“待确认”，可在对话表格或工作台原位修改；同项目所有对话同步使用修改后的范围。
- 不同项目互相隔离。同项目的对话消息分别保存，研究底稿共享。后续报告以生成时的范围、数据依据和图表快照为准，不随底稿变化覆盖历史。
- 当前项目的专利数据、统计结果与真实报告仍保持未生成状态。图表区嵌入本地自绘的技术路线、年度趋势、主体矩阵和地域分布四张示意图，统一注明“示意图 · 非项目分析结果”。示例主题为无人机自主降落，数量均为模拟数据，主体使用 A–E 的虚构名称。

## 概览与布局计划

- 概览展示三条机会线索、三项风险关注和四项有顺序的建议行动。桌面为机会与风险双栏，行动清单在下方；移动端纵向排列。
- 机会包含方向、依据、证据缺口、已有布局概况和验证状态；风险的关注级别与验证状态分别展示。统一使用“无人机自主降落”示例，不替代项目真实分析。
- 布局与路线图展示 P1 优先研究与验证、P2 补证后推进、P3 跟踪与储备，并说明拟研究主题、目标场景、排序理由、推进条件和具体行动。
- 三个阶段为补检与复核、方案比较与技术验证、布局评审与持续跟踪；分别展示行动、交付物、下一阶段进入条件和“待分配”的责任人。
- 概览、候选方向详情、优先级和阶段通过同一组线索与行动关联，支持定位查看。“带入对话”只预填要求，不自动发送、不提前保存对话历史。
- 内容来源统一位于 `assets/decision-insights.js`。工作台读取示例，报告在生成时深拷贝为版本快照；不写入项目真实分析字段，也不扩展 URL 摘要。
- 新报告示例直接包含机会与风险、专利布局建议、实施路线图。旧报告不会自动补写，点击“完善布局与路线图”后生成下一个版本并显示真实章节差异，旧版保持原样。

## 报告编辑设计

- 报告版本记录指令、改动摘要、来源对话、父版本及内容快照。新版本直接展示，旧版本保留。
- 对话中的改动卡片可“查看改动”或打开指定版本；差异视图显示真实的前后文字及章节顺序，支持定位到内容。
- 版本选择只切换浏览；“切回旧版”改变当前采用的版本。切回 V3 后继续使用示例指令会生成 V5，并保留 V4。
- 选中标题、段落或章节文字后，在文字旁出现修改输入栏，可直接提交要求或“引用到对话”。没有逐段常驻的引用方框；对话输入中的引用以轻量摘要显示。引用保存来源版本和内容，修改历史引用前需先切回对应版本。
- 导航地图是多图集合，包含技术路线、年度演进、竞争主体与地域布局四个图位。每张真实图表分别标识图表版本，随报告快照保留。本轮先嵌入可点击放大的 SVG 示意图，不将图片写入项目数据或真实报告版本；已有图表 AI 编辑入口仍显示无数据状态。
- 尚未接入模型服务。同页编辑体验使用明确的示例指令，示例版本单独保存到该项目的 `patent-navigation-report-example-<projectId>` 中，不混入真实报告集合；用户提交的修改要求、引用和改动卡片保存在对应对话。刷新后仍可打开示例版本。

本地图表位于 `assets/charts/`，通过 `assets/chart-gallery.js` 嵌入导航报告与对应分析视图；无需联网，支持点击放大、Escape 关闭和焦点返回。

## 本地状态与兼容

- 完整记录保存在 `patent-navigation-projects-v3`，结构为项目底稿、项目报告集合、对话消息。
- v2 项目迁移取 `lastConversationId` 对话的**完整范围**；无有效最近对话则取首个。不混合不同对话的范围字段。
- v1 研究各迁移为一个同名项目和一个对话。迁移保留 ID 和消息，重复执行不会重复建项目；v1、v2 原存储值不修改，其他旧范围仍保留在旧记录中。
- URL 使用项目 ID、对话 ID 和视图定位，兼容旧 `research`、v1/v2 `groups`。新摘要只携带项目/对话标题、行业和年份，不携带消息、附件或报告正文。
- 缺少本机完整记录时仅显示只读摘要；新建对话可基于摘要中的范围继续，但不会恢复链接未携带的内容。
- 统一使用 `#workspace?…` 路由，支持刷新、前进后退和旧页跳转；未知 ID 显示提示。
- 每次保存前读取并合并浏览器中的最新记录，避免交错操作覆盖其他对话、范围字段或新增项目。
- 本地文件的记录受浏览器和文件地址限制，不作为跨浏览器或跨设备的完整分享与备份。

## 验证

运行 `node --test tests/*.test.cjs`。

状态测试覆盖旧数据迁移、项目共享底稿、独立消息、附件元数据、摘要隐私和多标签交错保存。报告测试覆盖 V3→V4、实际差异、旧版浏览、切回与 V5 分支，以及旧报告追加布局章节后保留快照。概览与路线图测试核对共享内容、关联入口、行动预填和默认路由。DOM 回归使用可用的 `jsdom` 在内存加载实际页面脚本；不读取用户浏览器数据，不调用模型或网络。
