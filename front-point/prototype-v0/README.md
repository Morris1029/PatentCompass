## 本次设计依据

`docs/plans/2026-10-10-patent-navigation-design.md`。
产品已同步为“行业专利导航报告助手”，旧的人机共创贡献审查界面已退出当前原型。

## 业务主线

1. 填写行业与进入、立项或方向选择问题。
2. 确认行业边界、技术分支、检索范围与口径。
3. 查看技术、主体和地域分析，回查依据。
4. 对候选方向补检，记录反例以及保留、修正或排除的理由。
5. 阅读导航报告，继续追问或确认新增范围后局部更新。

界面以简洁文字、普通表格、少量重点提示与折叠详情为主，未增加看板式统计卡片。

## 页面

| 文件 | 用途 |
| --- | --- |
| `index.html` | 行业、决策目标、应用需求及可选检索条件 |
| `scope.html` | 范围说明、通用技术分类结构与检索前确认 |
| `review.html` | 围绕技术、竞争、地域与候选方向的分析工作台 |

| `report.html` | 决策摘要、验证清单、报告交付与继续询问入口 |

旧入口 `upload.html`、`contribution.html`、`citations.html`、`visual.html`
会自动前往相应的新页面，兼容此前打开的本地链接。

## 范围与状态

- 纯 HTML 与共享本地 CSS，无 JavaScript、外部资源、专利库连接或真实分析功能。
- 输入控件、原生折叠、页内定位和本地页面跳转可用于体验设计；表单内容不会保存或执行检索。
- 行业保持用户输入，不固定具体赛道；共同状态为“范围草案 v0”。
- 不虚构专利编号、企业、统计结果、排名或专利原文。数据未取得的部分明确显示待导入或待确认。
- 候选方向 A 仅演示“初步线索 → 补检 → 反例 → 修正”的工作流程，不代表实际发现。
- 中国专题包含中外申请人；全球对照按实际覆盖。申请人所在地、申请布局地、有效保护地分别展示。
- 全景统计数据集与代表案例分开，法律状态、同族、日期与计数口径保留待核实项。
- Word、PDF 与真实图表等成果尚未生成。当前可查看完整报告 HTML 结构及浏览器打印版式。

旧的两版人机共创原型保留在 `prototype-v1`、`prototype-v2`；新设计文档未改动。
